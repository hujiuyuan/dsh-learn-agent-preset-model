# 费曼检验

讲不清就是没懂。这是每一节的检验环节，决定这一节算不算学会。

## 开始前

从 `learn status` 读这一节的标题和达标标准。这一节如果还要求「1 道新题」，先出题（不能是教学中讲过的原题），再做费曼。

## 步骤

**1. 请用户讲**
- 「假设我完全没学过，请你把『<这一节的主题>』讲给我听，最好举一个例子。」
- 用户讲的时候**不插话、不纠正**，等讲完。

**2. 扮学生追问**
- 针对讲得含糊、跳过、或者用词不准的地方追问，每次只问一个，最多 3 次。直接在回复里问，不给选项：真没学过的人不会替你列好答案。
- 追问要像真的没学过的人：「为什么会这样？」「那如果……呢？」「你说的 X 是什么意思？」
- 至少有一个问题问边界：「什么情况下这个不成立 / 容易用错？」

**3. 逐项判分**

AI 扮学生时很容易说「讲得很好」。**必须逐项判，不给整体印象分**：

| 项 | 合格标准 |
|---|---|
| 关键概念 | 这一节的核心概念都提到了，用词准确 |
| 因果关系 | 说出了「为什么」，不只是「是什么」 |
| 例子 | 自己举了例子，并且例子是对的 |
| 追问 | 每次追问都接住了 |
| 边界 | 能说出至少一个不成立或容易用错的情况 |

**4. 给结果**

把判分表给用户看，每项一行：合格 / 不合格 + 一句原因。

- **5 项全部合格**（且新题做对）：
  `learn done <节> --pass --note "新题：<结果>；费曼：概念✓ 因果✓ 例子✓ 追问✓ 边界✓"`
- **任何一项不合格**：指出是哪一项、卡在哪里，盲点当场 `learn mistake <节> "<错误或缺失的理解>" "<正确理解>"`，然后
  `learn done <节> --fail --note "<哪几项不合格、原因>" --steps '["补<不合格的项>","费曼检验"]'`。脚本把检验这一步记完，追加你给的补练步骤（不给 `--steps` 就追加「补练没过的那一项 → 重新检验」），然后按新的位置条回到教学针对那一项补。

脚本提示「连续 2 次未达标」时，按人设里的换教法规则处理。

检验期间每轮回复最后一行也是位置条：原样抄 `learn now`（或刚运行的 learn 命令）的输出。

## 阶段大复盘

每学完一个阶段做一次：让用户把这个阶段的几节串起来讲，重点问节与节之间的关系。判分同上，不合格的部分对应的节用 `learn review --lesson <节号> --reason "…"` 标为需复习。

## 禁止

- 用户讲的时候插话纠正。
- 没逐项判就说「讲得很好」。
- 用户说「我懂了」就算过。
