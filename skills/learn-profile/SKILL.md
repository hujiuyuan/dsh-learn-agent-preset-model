# 学习者画像

画像跨课程记录用户会哪些技能、程度和证据，存在本地 `~/.dsh/learning/profile.json`（连了同步仓库时也随进度同步到用户的私有仓库），只由 learn 脚本读写（查看和纠正用 `learn profile`）。档位由脚本按证据算，你不要自己判断或报数。

## 用户问「你记得我什么」

运行 `learn profile`，把输出原样给用户看（每条带 id、来源、日期）。不要凭印象复述，也不要加评价。

## 用户纠正

用户说的正是先修问答里待问或待验证的那项：用 `learn prereq answer` / `learn prereq quiz` 记，不用下表（脚本会拒绝 `profile add / verify`）。问答期间顺口说到的其他技能，照下表记。

| 用户说 | 做法 |
|---|---|
| 「我其实不会 X」「X 我只会一点」（比记录低） | 直接采信：`learn profile add "X" <none|partial> --quote "<用户原话>"` |
| 「我会 X」（比记录高，或没有记录） | 先出 1 道验证题（预测输出 / 找错 / 解释为什么；用选择题时选项和说明不能暗示答案）。答对并说出原因：`learn profile verify "X" mastered --detail "<题目要点和回答>"`；答对说不出原因记 partial；答错记 none，并用一句话说这题暴露了什么 |
| 「删掉这条」（刚收到回执时） | 照回执里的命令：`learn profile forget e<N> --name "X"` |
| 「别记 X 了」 | `learn profile forget s<N> --name "X"`（整个技能，先 `learn profile` 查 id） |

`--name` 一定带上：开了同步时编号可能被合并改掉，脚本核对 id 和技能名对得上才删，对不上会列出现在的 id，按它重新删。

`--quote` 放用户原话；`--detail` 只写题目要点和结果，不写「精通」「专家」「完全掌握」「熟练掌握」「完全理解」「完美」，脚本会拒绝。不记姓名、单位、联系方式等和学习无关的信息。

## 暂停和清空

- 「先别用画像」：`learn profile off`。数据保留，不读不写，不再拿它打比方、跳过提问或给跨课程的教法建议。恢复：`learn profile on`。
- 「全部删掉」：先告诉用户后果：「会永久删除画像里的全部技能和证据，连备份一起删，不能恢复；课程进度不受影响」；连了同步仓库的再加一句「同步仓库的历史记录里还留着清空前的版本」。用户明确说确认后才运行 `learn profile reset --confirm yes`。原来是暂停状态的，清空后仍然暂停。
- `forget` 删的条目也会从备份里一起删掉。

## 什么时候会写进画像

只有这四种，都由脚本自动记录并输出「画像：」回执，你原样转告：

1. 用户自己说的：先修问答里的选择（A / B / C；选 D 不记），或明确纠正自己的水平
2. 验证题的结果
3. 先修节检验通过
4. 结业

项目文件里的线索、你自己的推断、聊天时顺带提到的，都不写。
